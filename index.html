Soy Joaquín Tomás Lobo, estudiante de la Tecnicatura Universitaria en Programación en la Universidad Tecnológica Nacional (UTN), viviendo en Capitán Cáceres, Tucumán.

Mi enfoque se centra en crear software confiable y bien estructurado. Me interesa tanto la lógica profunda (algoritmos, persistencia en bases de datos relacionales, procesamiento en segundo plano) como el desarrollo de interfaces funcionales y modernas en escritorio (C#/.NET/WPF), aplicaciones móviles y web.

Me gusta entender cómo funcionan los sistemas por dentro: desde la gestión de recursos en C/C++ hasta la reactividad moderna de TypeScript y el empaquetado nativo para Android.

Software de Escritorio • Windows

BUSCAPP (C# / .NET 8)

Disponible en GitHub

Aplicación de escritorio de alto rendimiento desarrollada en C# 12 y .NET 8 con interfaz moderna en WPF/XAML. Integra navegación web aislada mediante WebView2 (Chromium), extracción y descarga multimedia multihilo con yt-dlp, y procesamiento y conversión a audio MP3 de 320 kbps mediante multiplexación con FFmpeg.

Arquitectura & Detalles Técnicos
UI / UX WPF con aceleración por hardware, animaciones Storyboard y soporte dinámico de temas claro/oscuro.
Motor Web & Media Microsoft WebView2 + backend yt-dlp y FFmpeg para stream multiplexing y SkiaSharp para gráficos.
Persistencia & Packaging Configuración en JSON de alta velocidad (System.Text.Json) e instalador x64 generado con Inno Setup 6.
C# 12 .NET 8.0 WPF (XAML) WebView2 yt-dlp FFmpeg SkiaSharp Inno Setup

App Móvil • Android & Web

LaminaFacil

Próximamente en Google Play

Aplicación móvil orientada a la creación y diagramación de láminas escolares y posters de gran escala divididos en hojas A4 estándar. Cuenta con motor gráfico propio sobre HTML5 Canvas para corte de precisión con marcos y ensamble tipo Posteriza, y compilación nativa Android mediante Capacitor.

Arquitectura & Detalles Técnicos
Frontend & Motor Gráfico React 19 tipado con TypeScript, Tailwind CSS y motor HTML5 Canvas para renderizar cortes e ingletes a 45°.
Generación de Documentos jsPDF para exportación vectorial multipágina con márgenes calibrados y guías visuales de corte.
Ecosistema Android Capacitor 8 (Filesystem & Share), compilación AAB con Gradle, OpenJDK 21 y firmado digital SHA-256 (Keytool).
React 19 TypeScript Capacitor 8 Android SDK HTML5 Canvas jsPDF Tailwind CSS
